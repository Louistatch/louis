LIVE228 Clash 🇹🇬
Le moteur TikTok local n'est pas démarré.
1. Ouvre Termux
cd ~/live228-clash-v02-termux
./start-termux.sh
2. Laisse Termux tourner en arrière-plan.
Reviens ensuite dans LIVE228 Clash.
3. Pour diffuser depuis le même téléphone
Lance un LIVE TikTok en mode jeu/partage d'écran si cette option est disponible sur ton compte, puis reviens dans LIVE228.
Ouvrir TikTok
Aucun PC nécessaire. Le moteur et le jeu tournent sur le même téléphone.
