# LIVE228 Clash Studio

Version Windows de LIVE228 conçue pour TikTok LIVE Studio.

## Flux recommandé

1. Ouvrir TikTok LIVE Studio et se connecter.
2. Ouvrir LIVE228 Clash Studio.
3. Démarrer le LIVE dans TikTok LIVE Studio.
4. Dans LIVE228, saisir le @username puis cliquer sur **Connecter au LIVE**.
5. Appuyer sur **F1** pour passer en Mode Studio (terrain seul).
6. Dans TikTok LIVE Studio : **Ajouter une source > Capture de fenêtre** puis choisir **LIVE228 Clash Studio**.
7. Ajuster la source dans une scène portrait 9:16.

Les commentaires, entrées, likes, follows, partages et cadeaux reçus par le connecteur sont transformés en actions dans le jeu.

## Important

La lecture des événements LIVE utilise tiktok-live-connector 2.5.0, une intégration non officielle du service Webcast TikTok. Pour une exploitation commerciale à grande échelle, privilégier l'accès officiel TikTok LIVE Interactive Games / partenaire lorsque disponible.
